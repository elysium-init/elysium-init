Сейчас веду инфраструктуру B2B SaaS-платформы:
**~80 микросервисов · ~300 воркер-нод в трёх зонах доступности · до 10 тыс. RPS на Ingress.**

## Что сделал

- **Ресурсы кластера:** вместе с разработчиками пересмотрел requests и limits по p99. CPU requests пула снизились примерно с 4 000 до 3 000 vCPU, а новые сервисы добавлялись без дополнительного бюджета.
- **Рефакторинг Terraform:** описания Node Groups и сетей были скопированы в пять state-файлов. Вынес их в общий модуль и перенёс адреса блоками `moved` без пересоздания ресурсов. Объём кода сократился на 40% (~10 000 → ~6 000 строк).
- **Стандартизация CI/CD:** перевёл 20+ репозиториев на общие версионируемые шаблоны GitLab CI (Kaniko → registry → обновление тега в GitOps-репозитории). Свёл ~15 скопированных чартов к общему Helm-шаблону с values-файлами по окружениям.
- **Автомасштабирование:** HPA по CPU и по кастомным метрикам (RPS, Kafka consumer lag) через Prometheus Adapter, с учётом лимитов соединений к базам.
- **Алертинг:** заменил абсолютные пороги ошибок на алерты по доле ошибок с порогом по минимальному трафику. Тихие ночные отказы перестали пропускаться.
- **Логи:** Vector → Kafka → OpenSearch. Убрал отставание доставки до 4 минут в пиках за счёт масштабирования консьюмеров, батчинга и сжатия.
